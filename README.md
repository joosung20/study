# 📚 StudyAI - 스마트 AI 학습 플래너

시험 날짜와 공부 과목을 입력하면 AI가 맞춤형 학습 계획을 자동 생성해주는 웹 애플리케이션입니다.

## 🚀 프로젝트 소개

StudyAI는 학생과 수험생이 효율적으로 학습 계획을 세울 수 있도록 설계된 AI 기반 학습 플래너입니다.

사용자가 시험 일정, 공부 가능 시간, 과목별 난이도를 입력하면 자동으로 학습 로드맵을 생성하고 학습 진행 상황을 관리할 수 있습니다.

---

## ✨ 주요 기능

### 🎯 AI 학습 플랜 생성

- 시험 날짜 기반 학습 기간 자동 계산
- 과목별 난이도 반영
- 공부 가능 시간 반영
- 휴식 요일 설정 가능
- 단계별 학습 전략 자동 추천

### ⏱ 집중 타이머

- 스탑워치 방식 집중 시간 측정
- 과목별 타이머 연동
- 누적 공부 시간 자동 기록

### ☕ 휴식 타이머

- 사용자 지정 휴식 시간 설정
- 카운트다운 기능
- 휴식 종료 알림 제공

### 📅 자유 캘린더

- 날짜별 개인 일정 작성
- 할 일 추가 및 완료 체크
- 학습 진척도 시각화

### 📊 학습 대시보드

- D-Day 표시
- 전체 달성률 확인
- 누적 공부 시간 통계
- 미완료 학습 알림

### 💾 로컬 저장

- LocalStorage 기반 데이터 저장
- 회원 정보 저장
- 학습 플랜 저장
- 캘린더 데이터 저장
